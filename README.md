# 泊一区 夏祭り2026 — フィールドワーク・デジタルアーカイブ（叩き台）

## 概要
泊一区公民館で開かれた夏祭り（2026-07-25 18時〜）の記録写真を、
**撮影時刻メタデータ（EXIF）** を読んで時系列に整列し、スライダーで
「祭りの時間を進める」インタラクティブなHTMLサイトにしたもの。

## 構成
| ファイル | 内容 |
|---|---|
| `index.html` | 本体。写真90枚分のメタデータを焼き込み済み（静的、単体で完結） |
| `photos/tn_*.jpg` | タイムライン用サムネイル（幅340px・約35KB） |
| `photos/med_*.jpg` | メイン表示・拡大用（幅1200px・約180KB） |
| `photos/poster.jpg` | 左パネル概要の告知ポスター |
| `meta.json` | 時系列ソート済みメタデータ（作り直し用・作業資料） |

- 対象: 本体フォルダ `とまり大学2026夏祭り/静止画` の **90枚**（`IMG_*.JPG`）
- `使わない写真/` サブフォルダ（45枚）は除外。

## レイアウト
- **左パネル**: タイトル / 告知ポスター / 概要 / 操作説明 / タグ
- **メイン上**: 選択中写真の大きな表示（クリックで拡大）＋ 自動再生
- **メイン下**: 横タイムライン（写真をジグザグ配置）＋ スライダー（「石」ノブ）
  - ノブを右へ→撮影順に写真が「現れて」、祭りが進む。左へ→巻き戻し。
  - 未到達の写真は半透明、到達で色がつく。現在地はノブに縁取り＋ロゴリング。

## 生成方法（叩き台を直すとき）
1. EXIF抽出: `exiftool -json -DateTimeOriginal -ImageWidth -ImageHeight IMG_*.JPG`
2. サムネ生成＋時系列ソート: Python(PIL `ImageOps.exif_transpose` で縦横正す)
3. `meta.json` → `index.html` の `const D = [...]` に焼き込み

## 実データの時系列
- 7/24 15:52（前日・2枚）→ 7/25 13:41（設営~）→ 17:33（夕方・出店準備）
- → 20:00頃（抽選会・夜の賑わい）→ 22〜23時（後夜祭）→ 7/26 00:02（片付け）
- 解像度の大半が 6000×3368（1枚約6MB）。表示用サムネで12.9MBに圧縮。
